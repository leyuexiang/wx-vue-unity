# 管理导航统一设计

日期：2026-11-10。任务：NAV-01。用户明确将资源、场景和物联网菜单统一；本设计覆盖此前仅IoT动态、资源/场景静态的过渡约定。

**NAV-02修正：** 用户随后指出一二级目录应保留原样。当前固定展示“资源管理→模型管理/图片管理/模板管理”“场景管理→场景列表”“物联网管理→连接器管理/设备绑定/接收记录”。后台授权树用于决定哪些页面可用、隐藏父级、模块内顺序及权限，前端按白名单页面所属模块投影为上述两级；后台应用包装、扁平菜单或任意目录名称不直接替换业务分类。此修正覆盖下文NAV-01关于显示名/任意层级直接透传的旧约定。

## 1. 权威与边界

复用系统菜单及角色分配，标准后台使用 `/admin-api/system/auth/get-permission-info` 的授权menus树。后端决定授权页面、可见范围、模块内顺序和角色；前端依据已编译组件白名单映射固定业务分组、显示名和路由，绝不以服务端字符串导入任意文件或外部地址。后台应用目录层级只用于授权过滤，不直接替代产品原有一二级目录。

资源、场景、物联网按产品确认的名称和顺序共用一级分类标题，授权页面直接作为二级入口展开。后台删除/隐藏入口后，前端导航与地址准入仍关闭；没有授权页面的分类不显示，不能因为固定分类而补出未授权页面。

## 2. 页面合同

| 路由名 | component标识 | 查询准入 |
| --- | --- | --- |
| modelManage | resourceManage/modelManage/index | 菜单 + dim3d:model:query |
| iconManage | resourceManage/iconManage/index | 菜单 + dim3d:icon:query |
| templateManage | resourceManage/templateManage/index | 菜单 + 现有运营端模板能力；接口继续按实际角色/业务权限判断 |
| sceneManage | SceneManage/index | 菜单 + 有效登录；现有场景读取按可信租户及对象范围，不新造scene:query权限 |
| iotConnectors | iotManage/connectors/index | 菜单 + iot:connector:query |
| iotBindings | iotManage/bindings/index | 菜单 + iot:device-binding:query |
| iotMessages | iotManage/messages/index | 菜单 + iot:message-inbox:query |

目录及未知页面不映射为可跳转路由；重复页面只保留第一次授权位置。解析沿用1000节点/12层上限。菜单只负责入口准入，不替代接口逐次鉴权，也不改写原有资源归属、发布与编辑器对象授权。

## 3. 身份兼容与失败恢复

标准独立登录保留menus；参考服务的资料响应和经过来源校验的宿主鉴权允许可选menus，未提供时不能从角色或通配权限合成完整导航。标准后台的内嵌/交接身份可用同一令牌补读，不采纳返回结果扩大宿主权限。

首次鉴权完成、业务视图挂载前与站内跳转共用准入规则。请求菜单失败、空菜单、未知组件、没有任何可用页面时进入独立的管理访问提示页，不挂载资源或场景业务页面，不循环跳回无权限场景；允许刷新权限并重新选择首个可用页面。退出/身份切换清理菜单，迟到响应不覆盖新身份。

## 4. 迁移与验收

提供资源/场景菜单增量配置清单，沿用系统接口逐级创建/复用及角色分配，配置父编号与租户套餐，不直接SQL绕过缓存，不自动授予所有角色。现有旧测试初始化只创建模型按钮权限，不能视为已具备页面菜单，部署必须核对。

清单：[资源与场景](../../../../Server/jtyf-cloud/db/system/editor-management-menus.json)、[物联网](../../../../Server/jtyf-cloud/wx-module-iot/db/iot-management-menus.json)。先配置目标环境的页面目录及现有角色权限，核对标准授权树中component完全匹配本表，再发布前端；已有按钮权限优先复用，不能重跑旧初始化覆盖业务数据。

先失败用例，再实现统一导航、渲染与首次/站内准入。验证七页面映射、排序、隐藏父目录、权限交集、模板租户限制、未知/重复组件、空菜单恢复及身份隔离；浏览器回归同时核对三个同级分类与无权限地址不发业务请求。实际环境授权及真实网关部署另记，不以传输替身冒充联验。

2026-11-11配置侧统一：资源/场景与IoT清单使用相同版本及`groups/pages/buttons`结构，统一工具执行预览、增量配置及留证回退，保留已有按钮与角色授权。前端仍消费同一标准授权树，不直接读取部署清单。148实际菜单/套餐/身份核对和工具验证见[配置交接](../../../../Server/jtyf-cloud/docs/evidence/iot-management-20261111/README.md)；当前尚未应用线上授权。
