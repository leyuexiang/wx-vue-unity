## 调用与生命周期审计（M1-01）

| 调用位置 | 改造前行为 | 本批处理 |
| --- | --- | --- |
| `scene-platform/commands/moveSceneNodeCommand.ts` | 每次准备换父级或排序命令构建完整索引 | 使用场景存储的共享索引 |
| `scene-platform/commands/collectEditableSceneSubtrees.ts` | 复制、删除预检查各自扫描完整集合并排序 | 使用同一个共享索引 |
| `views/sceneEdit/SceneLeftPanel/components/StructurePanel/useStructurePanel.ts` | 通过面板层级修订按需构建索引，并保留旧映射比较后续事件 | 保留至M2适配；不可直接换成实时映射，否则可能破坏旧/新记录比较 |
| `unity-runtime/runtime/projectSceneForUnity.ts` | 对独立投影快照构建并校验完整索引 | 保留，作为协议边界校验 |
| `integrations/scene/sceneFourPackage.ts` | 保存转换前完整校验 | 保留，不能因编辑缓存存在就跳过待保存快照校验 |
| `scene-platform/store/sceneStore.ts` | 原先不拥有共享父子索引；部分重编号变化没有独立对象事件 | 存储拥有缓存，所有对象写路径同步登记；重编号回调改为提供新记录 |

新缓存首次读取时全量构建，此后普通属性只更新记录引用，不分配结构工作集合。新增、删除、换父级和重排合并为待处理记录，读取时检查最终结构，再更新受影响父级；无关兄弟数组保持引用。结构版本仅在结构变化或重新构建时推进。

重载和同步事务回滚清除缓存，下次从当前完整草稿重建；异步确认失败通过既有反向补偿路径登记更新。缓存直接归场景存储所有，不新增全局映射或事件订阅，生命周期随存储；不额外延长宿主和草稿的生命周期。

## 验证范围（M1-02/03）

新增`sceneNodeIndexCache.test.ts`13项及`sceneStoreNodeIndex.test.ts`9项，共22项。覆盖：

- 2万节点深链及宽树，以父字段读取次数不超过节点数5倍检查结构扫描；兄弟排序成本独立计算，不声称全量排序为线性。
- 重复编号、孤儿、自环、双节点环及越界顺序；既有同值顺序用例继续回归。
- 连续属性更新不重复读取完整集合、不替换兄弟数组、不推进结构版本。
- 换父级、新增/删除、同值排序与完整索引结果对照；无关父级集合保持引用。
- 父子乱序批量新增、子树删除/恢复、插入导致的隐式兄弟重编号。
- 同步事务失败（含事务内曾读取索引）、异步确认失败补偿、同编号场景重载、命令撤销重做。

开发时先运行新增用例，缺少缓存模块导致失败；接入后定向用例发现重编号回调传旧记录的问题，修正后执行全量回归。

## 保留边界

本批减少编辑命令重复构建索引，不代表节点编辑整体已实现局部复杂度。原对象数组查找、重编号、层级提交排序以及事务完整草稿复制仍存在，运行端仍接收完整快照；这些成本在后续数据与批处理阶段处理。

结构面板、独立保存及Unity协议投影仍按各自边界构建索引。尚未执行浏览器、真实Unity或服务端联验，也未做设备耗时与内存实测。M1-04及后续世界变换、显隐锁定传播仍待实施。
