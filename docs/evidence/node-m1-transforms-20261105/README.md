# NODE-M1-04：统一局部与世界变换查询

日期：2026-11-05。范围：Web纯领域变换查询、场景存储缓存及现有换父级命令。无新增依赖，不修改Unity、后端或部署。执行状态统一见Unity计划05第12.3节。

## 方案与修改

原有局部矩阵、父链世界矩阵、相对变换分解均在`moveSceneNodeCommand.ts`内部。复用其列式仿射矩阵、内禀XYZ欧拉角、负缩放和奇异位处理，将计算集中到`scene-platform/core/sceneNodeTransforms.ts`；没有保留另一套换父级算法。

场景存储提供只读`getObjectLocalMatrix(id)`与`getObjectWorldMatrix(id?)`。省略世界查询编号返回本地场景根矩阵；缺失节点和地理节点拒绝本地查询。派生矩阵不包含引擎对象、不反写草稿、不保存到四包；平移列不共享原业务数组。矩阵可以表达世界空间剪切，换父级写回平移/旋转/缩放时仍拒绝无法表示的剪切、不可逆目标及非有限值。

局部和世界矩阵按需计算。世界查询沿最近已缓存祖先迭代向下计算，复用公共父链，不递归、不为每个兄弟重新计算全部祖先。父级或姿态变化登记脏根，查询前沿当前父子索引去重清理受影响子树的世界缓存，无关子树和子节点自身未变的局部缓存保留。待处理栈与访问集合按场景复用。

存储的新增/替换/插入、删除/恢复、层级提交、同步回滚、异步反向补偿及同编号重载均接入失效管理。自身矩阵在删除/替换时立即释放；重载和同步事务回滚清理全部派生缓存。正常名称、显隐、锁定及排序变更不触发变换传播；变换对象被复制但字段相同（含标量缩放与等值三轴缩放）时也保留缓存。

换父级命令使用同一查询入口，整批共享一次目标逆矩阵，所有节点验证成功后才写入草稿；原有命令原子性、撤销重做和失败补偿不变。

## 实际验证

新增`sceneNodeTransforms.test.ts`23项，先运行缺少模块的失败用例，再实现并验证。覆盖：

- 三个单轴旋转方向、父旋转/缩放作用到子位置，以及通过独立逐点旋转对照多轴旋转、非均匀缩放和镜像组合。
- 两万节点深链迭代计算；第二次查询和公共父链不重复读取变换记录，以访问次数和矩阵引用检查缓存复用。
- 同批父子多次编辑只读取最终结果；无关子树、同序重排、普通属性和等值变换副本保留缓存。
- 转移出已脏父级的子树使用最新父链；同编号替换/删除重建、删除恢复及同编号场景重载不读取旧矩阵。
- 换父级、撤销重做、异步确认失败反向补偿保持世界姿态；同步事务内读取临时矩阵后失败可恢复。
- 欧拉角奇异位和负缩放往返、世界剪切保留/局部分解拒绝、零缩放不可逆拒绝、非有限输入和有限输入组合溢出后修复重试。
- 查询不修改完整草稿，地理与缺失节点明确拒绝。

## 验证边界与下一项

本次未执行浏览器、真实Unity或服务端联验，也未做设备耗时与内存实测。局部/世界缓存带来派生矩阵驻留成本，是否需要进一步压缩以M4固定设备测量为准；无变化节点不主动计算，但不承诺任意操作恒定耗时。

本批仅统一Web逻辑查询与原命令，尚未将运行端锚点改为数据列，也未改变完整草稿投影、现有数组查找/排序/事务复制。变换的脏子树机制不等于M1-07全部完成；有效显隐、锁定及后续空间派生仍需接入。下一项为M1-05，随后M1-06。
