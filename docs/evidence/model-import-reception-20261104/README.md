## 实现

模型弹窗不再调用旧uploadConvert：先由工作线程分片计算原ZIP的SHA-256，创建受控导入，取得原文件短时目标，独立PUT上传，submit入队，再由用户查询状态。上限调整为500MiB（界面显示500MB）；只接收非空ZIP，具体模型/贴图合法性由后端核验。

默认产物为GLB，与本期模型清单合同一致。新增时SYSTEM/MINE映射为GLOBAL_SYSTEM/TENANT_SHARED；可信租户和操作者仍由服务端校验。编辑文件时先读取原资源currentRevision并使用REPLACE，不把替换悄悄改成新CREATE；旧未受管资源或跨来源替换由后端拒绝，无旧接口回退。

签名PUT走独立fetch、credentials=omit、禁止重定向、不携带Authorization/ClientId/租户头，不复用业务401处理。目标必须HTTPS并匹配原输入摘要及大小。原文件传输/202入队都不绑定可用编号；只有importStatus和operationStatus同时COMMITTED且修订合法才写modelFileId。

网络重试保留原operationId与不可变输入；已入队不重复PUT/submit。当前浏览器页签的sessionStorage仅保留请求、文件名与范围，不存文件字节或签名地址；以认证令牌的摘要及编辑记录隔离恢复项，重开后先查询，不信任本地成功状态。切换身份、关闭或卸载终止本地工作线程/请求，不声称取消后端任务。会话令牌更换后旧恢复项不自动用于新身份，后续任务列表查询能力另接。

原ZIP按1MiB切片在工作线程计算摘要，SHA压缩轮沿用项目现有算法，状态和64字节块复用，避免整文件arrayBuffer和主线程长计算；原存档修复代码不修改，不引入第三方依赖。
