# NODE-M1-05：自身与有效显隐传播

日期：2026-11-05。范围：Web逻辑显隐缓存、场景存储、运行时桥接和面板有效状态适配；无新增依赖，未修改Unity、服务端、数据库或部署。执行状态统一见Unity计划05第12.3节。

## 改造前事实

显隐命令只改对象自身字段，桥接层叠加该对象的图层显隐，没有统一派生业务父链，也不会在父显隐变化后向其他运行端同步整棵受影响子树。Unity兼容锚点可通过引擎父子层级遮住孩子，但不能据此声称Web逻辑状态、无引擎快照及恢复路径已完整一致。

## 实现与所有权

- 新增纯领域`sceneNodeVisibility.ts`。最终显隐为“自身可见且自身图层可见且父节点最终可见”。每个节点的自身值继续保存在完整草稿，父级隐藏不改子值；父级图层的隐藏通过父链传递，子节点自己的图层独立生效。
- 场景存储提供`getObjectVisibilityState`，返回自身、继承及有效值；面板复用同一查询。有效值不进入四包，不产生后代编辑范围，也不依赖资源是否已驻留。
- 缓存沿已校验父链迭代计算，复用公共祖先。显隐、父级和图层归属变化登记受影响根，按当前树去重失效；普通名称、变换、顺序不重算显隐。新增/替换/插入、删除/恢复、图层增删、同步回滚、异步补偿及同编号重载均维护缓存。
- 增加图层到节点编号的反向成员索引。首次按需建立，后续只维护变化成员；图层显隐同步不再每次扫描完整对象数组。
- 原对象/图层事件的可选`visibilityChanged`只标记运行投影传播范围。桥接在批次边界合并根并去重收集后代，从最终草稿投影有效显隐；不伪造子节点业务编辑事件。普通改名仅同步自身，层级批量变化仍沿原完整快照路径。
- 独立运行快照解析器改变临时父显隐时，在该快照自己的树上派生，避免与当前可保存草稿混用。临时编辑/拖动驻留意图仍走原独立通道。
- 显隐命令撤销只恢复原自身显隐，不再以整条旧对象覆盖后来到达的名称、姿态或其他配置。

新增覆盖包括：父隐藏/恢复保留子自身意图；隐藏期间修改子意图；父子不同图层；保存四包保持自身值且不扩展子编辑范围；改名与变换保留派生记录；2万节点深链及重复访问次数；图层切换不重复扫描节点/图层；换父级、删图层、批量删除恢复、同编号替换/重建/重载；同步事务失败和异步反向补偿；显隐回放保留其他属性。

桥接检查使用真实场景存储、命令总线及内存运行端：父隐藏/恢复同步相关子树且不全场重载，不触碰无关节点；同批多次父子编辑只同步一次最终结果；图层移除恢复默认显隐；临时驻留意图不写草稿；外部临时快照继承一致；注入部分运行同步失败后反向补偿并完整重同步，恢复画面快照、历史栈及子自身意图。

## 验证边界

未执行浏览器、真实Unity和服务端联验，未做设备耗时/内存实测。内存运行端验证的是桥接请求与快照，不作为真实资源装卸通过的证据。预览规则的运行期临时覆盖和真实引擎行为保留联合验收范围。大子树的同步量仍随受影响节点数量增长，运行端批量协议与预算留后续阶段，不据本批声称延迟达标。本批统一编辑草稿的显隐传播，没有实现锁定父链或把全部派生系统合成同一工作队列；下一项M1-06，M1-07/08继续收口。
