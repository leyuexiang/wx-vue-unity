# NODE-M1-06：有效锁定、编辑入口与失败补偿

日期：2026-11-05。范围：Web逻辑锁定、命令、运行投影、旧档还原及相关补偿；无新依赖，未修改Unity业务代码、服务端、数据库或部署。状态统一见 Unity 工程[场景节点树与空间分块执行计划](../../../../Unity/jtyf-dts-webgpu/Assets/docs/plan/06-场景节点树与空间分块执行计划.md#123-设计14实施任务明细)。

## 原有缺口

- 通用`isObjectEffectivelyLocked`只查自身与图层，批量节点命令另有父链检查；属性、创建等入口的规则不一致。
- 桥接锁定投影没有沿父链传播，后代的操控/拾取快照可能仍为可编辑。
- 换父级在准备时检查锁定，执行时未复核；复制重做复用原批次时也没有完整复核当前源和原目标父级。
- `sceneDefinition.ts`兼容归一化根据可拾取字段覆盖显式锁定，可能导致重开丢失自身锁定。四包还原还会为缺失锁定先填false，掩盖旧档推导条件。
- 继承锁定生效后，撤销失败的默认反向执行可能被新编辑门禁拒绝；单对象删除的隐式兄弟重编号也需要精确恢复。

## 实现

`sceneNodeLock.ts`提供自身/继承/有效锁定。有效锁定为自身、图层或父节点有效锁定中任一成立；深链使用显式栈，公共祖先结果缓存。图层锁定查表一次初始化，成员编号复用M1-05反向索引；图层写入只记脏编号，在最终批次查询时取成员，避免校验父子新增中间状态。锁定缓存与显隐/矩阵独立失效，重载和同步回滚清理。

场景存储统一`getObjectLockState/isObjectEffectivelyLocked`，对象/图层事件以可选`lockChanged`标记传播范围。桥接与显隐共用批次去重集合，向相关子树投影有效锁定和临时`pickable=false`，原始自身锁定和独立拾取配置不变。面板适配使用相同判定，独立运行快照在其自身父树上派生。

普通名称、变换、样式、配置、显隐、移组、删除和复制使用同一查询；创建/同编号覆盖补齐源、父级及目标图层检查。自身锁定可自行解锁，继承锁定须先解锁父级或图层。换父级执行/重做复核当前源、目标类型、锁定及目标父链；复制重做复核源子树及副本原外部父级。底层存储保留加载、撤销和补偿能力，不作为用户编辑门禁。

明确保存的`locked`优先于可拾取状态；仅缺失锁定的旧档从`pickable/pickup`推导，旧别名继续迁移。四包还原在填默认值前使用相同缺失回退。旧创建入口没有独立锁定来源，保留其初始兼容推导并修正注释。

现有`captureRollback`钩子增加当前存储参数，原无参闭包仍可使用。对象字段直接恢复捕获记录；创建/删除/复制/移组及图层删除捕获相关成员、兄弟原位置/顺序与区块引用。`restoreObjectBatch`的可选替换模式服务失败补偿，默认模式仍拒绝重复编号。补偿保留显式删除集合、保存编辑范围和历史栈，不重新执行新编辑权限检查。锁定命令撤销只还原锁定字段，保留期间更新的其他配置。

## 验证

新增`sceneNodeLock.test.ts`37项，先运行缺少模块的失败用例，随后实现。用例暴露了显式锁定被可拾取覆盖、补偿受新门禁阻断以及兄弟顺序/删除标记恢复的边界，修正后复验。

| --- | --- |
| 最终`pnpm test` | 111组771项通过 |
| `pnpm type-check` | 初次集成通过，最终类型检查随生产构建复核通过 |
| 最终`pnpm build` | 通过；仍有依赖注解及大文件块提示，本批未调整拆包 |

覆盖范围：

- 父锁定/解锁保留子自身值和拾取配置；父子不同图层、图层增删、移组、删除恢复、同编号重载和同步回滚。
- 两万节点深链与重复读取计数；普通改名、显隐和变换不使锁定重算，锁定不使无关子树、显隐或矩阵重算。
- 显式锁定与相反可拾取值的直接解析和正式四包往返；缺失锁定及旧别名兼容。
- 11类编辑操作拒绝后保留草稿和历史；准备后源/目标锁定阻止换父级；复制重做查当前源及副本原目标；锁定图层内创建拒绝。
- 名称、变换、显隐、创建、复制、单删、批删、移组、删图层共9类撤销失败，在后到的父锁定下仍可补偿，草稿、数组顺序、派生索引、显式删除集合、字段编辑范围和历史位置保持一致。
- 内存运行端验证锁定/解锁的子树投影与拾取恢复、图层锁定跨子树传播、临时独立快照及运行部分失败后的完整重同步。

## 保留边界

未执行浏览器、真实Unity/服务端联验及设备性能测量。锁定是编辑约束，服务端鉴权和租约仍由原接口负责。大子树仍按受影响节点数同步，不声明延迟或内存目标达标。补偿仅捕获相关记录和兄弟引用，不额外深拷贝整场景；原同步事务的完整快照及其他全量成本仍存在。M1-07继续统一派生工作集合，M1-08统一集成回归，本轮不将M1整体标为完成。
